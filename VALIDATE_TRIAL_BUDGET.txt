READ
1. Budget is NOT the bottleneck. 5x the trials found an IS optimum 3-4x BELOW the known crown ($60-90k vs ~$310k),
   and never entered the crown's region (trail OFF, partial OFF, stop 2.5, target 5, filters .75/.8). All four crowns
   have trailing stop + partial exit ON and weak/zero vol filters = the known-losing family.
2. Seed noise (200 s42 lockbox -$9.7k FAIL vs 200 s7 +$81.7k WEAK) is BIGGER than the 200-vs-1000 difference.
   The wide-file verdict is a coin flip on seed, not on budget.
3. More trials makes the verdict HARDER to pass, not easier: DSR 0.66 -> 0.42 (the luck bar rises with n), 1000 = FAIL.
4. Half the draws die on min_trades (1126 evaluated for 600 valid), so a wide file wastes ~50% of any budget.
5. Decision: keep the scope defaults (80/120/200/300). The pipeline that works stays: offline hunt -> plateau ->
   fenced file -> Auto-Validate (which then exhausts the fence). If discovery itself is to improve, the lever is a
   smarter search (seed from DEFAULT_PARAMS / coordinate descent), not a bigger random+GP budget.
