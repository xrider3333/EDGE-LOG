BOOK QUEUE Q24 (scoping item B2) - SEASON r1: same-calendar-month return seasonality in single US stocks (Heston-Sadka 2008), as a monthly
basket SEAT on the RESMOM line. PRE-REGISTRATION, FRONTIER, 2026-10-08 (draft v1 to MANAGER 2026-10-07 18:17 MST; v2 the S1 engine rule; v3
AVG >= 1 year; v4 = MANAGER's review #115 / #116, GO WITH 4 EDITS, folded in below), committed before any number of this item.
Walk-forward only (owner decision b, 10-05).

WHY. Heston and Sadka (2008) found that a stock's return in the same calendar month of past years predicts its return this month (lag
12, 24, ... months), independent of momentum and reversal; Keloharju-Linnainmaa-Nyberg (2016) find the same across asset classes and say it
is a risk premium earned in specific months. It is a different clock from RESMOM (12-1 momentum) and BAB (beta): it is the house's cheapest
untested basket signal on held data (scoping doc B2). Q20's map: a seat must EARN ON R (the RESMOM line's drawdown days) to matter.
DATA LIMIT, stated first: the SIPORB stock cache starts 2016-01-04, so a rank in WF year k has only k prior same-month observations (1 in
2017, 9 in 2025); the published signal averages 10-20 years. Power is low and it rises through the stretch.

THE ENGINE = RESMOM r1's (tools/rocfrontier/r17_resmom.py, imported, never edited) through FRONTIER's r19_bab.py pattern (the scores and
the null's streams swapped, nothing else), JUDGED UNDER MANAGER #127's hygiene rule S1 = r17's post_mode 'close' ([HYG-S1], STRATEGY-
BEATING's restatement): no name is dropped for a flag inside the hold; flagged names ride the split-safe path; a spin-off / stock-dividend
ex-date inside the hold closes that position at the official close of the session before it. The registered 'remove' reading is NOT
run (it is the look-ahead TTM found). This prereg is not run until that r17 is on main; its pool, schedule, fills, costs, borrow,
dividends and Stage A rules are then used as is, and the seat read uses the S1-restated L (121.06, file e204dd53...).

THE TWO CELLS (a family of 2), each long the 50 HIGHEST and short the 50 LOWEST scores, dollar-neutral, $4,000 slots, monthly:
- LAG12: the name's split-safe total return in the SAME calendar month one year earlier (the month being entered, a year ago). Needs that
  month's returns complete (at least 15 finite daily returns).
- AVG: the mean of the name's same-calendar-month returns over EVERY prior year on file with a complete month (1 in 2017 .. 9 in 2025),
  at least 1 (v3: the two cells rank ONE shared pool, which needs both scores; requiring 2 years would empty 2017 for LAG12 too) - so AVG
  equals LAG12 in the first WF year and the cells differ from 2018; CHOICE: equal weights, no shrinkage. Both cells start at RESMOM's
  first rank with a full 252-session window (2016-12-30, entering January 2017: LAG12 = January 2016, the cache's first month).
Ties by symbol, as RESMOM. Both cells rank the same pool.

20 bps (MANAGER edit 4, below). A cell that fails is DEAD as a leg; its seat numbers are still printed.
