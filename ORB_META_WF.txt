READ
1. There is NO evidence that re-optimising helps, and the point estimates all run the other way.
   Re-optimising by risk-adjusted return earned $166k over the 11 forward years; leaving the parent
   defaults untouched earned $377k; a config drawn at random from the eligible field earned $312k.
2. The selection lands at the 38th percentile of the field on average. A rule with no skill would
   sit at 50. So the rule is not merely weak, it tilts towards configs that do WORSE next year.
3. It is not statistically decisive on 11 readings (sign test p = 0.23, CI touches zero). Treat it as
   the burden of proof moving, not as proof. But the bootstrap puts 97% of the mass below zero.
4. Selecting on NET did better than selecting on risk-adjusted return ($271k vs $166k) and still lost
   to leaving it alone. Consistent with maxDD being too noisy on a short window to select on.
5. CAVEAT, stated because it flatters us: the "today's crown" row ($385k) is CONTAMINATED - those
   params were chosen with full knowledge of these same forward years. It is an upper bound on
   hindsight, not a competitor. The only clean comparison is re-optimised vs left-alone vs random.
IMPLICATION: freeze the crown; the bar for any future re-crowning is not "it wins in-sample" but
"it beats leaving the parameters alone, forward". That is what this file measures, and it is cheap
to re-run on any strategy in the stack.
